# Kermi downloads

Official Windows installers for the Kermi apps, **Rota** and **Vexa**.

Get them from https://kermi.one. Create a free account, install, and sign in inside the app.
Windows 10/11, 64-bit. Windows SmartScreen may warn because the apps are new: choose *More info*, then *Run anyway*.

Releases in this repository:

- `v*`: the app installers.
- `engines`: data files the apps install and update by themselves (nothing to download by hand).
